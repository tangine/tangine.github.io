# JavaScript

## var, let, const的异同点
1. `var`是函数作用域，`let`、`const`是块级作用域
2. `var`允许重复声明，`let`、`const`不允许
3. `var`在非严格模式的普通脚本顶部会成为`window`属性，`let`、`const`不会
4. 都存在变量提升, `var`初始化为`undefined`，`let`和`const`存在暂时性死区
5. `const`必须初始化且不能再次赋值，但是复杂对象可以修改属性，`var`、`let`不用且能重复赋值

## 防抖和节流
| 特性     | 防抖 Debounce                        | 节流 Throttle                        |
|----------|--------------------------------------|--------------------------------------|
| 触发机制 | 事件停止触发后，延迟一段时间执行     | 在固定时间间隔内最多执行一次         |
| 执行次数 | 连续触发执行最后一次（或首次）       | 连续触发按固定频率执行               |
| 核心机制 | 每次触发都重置计时器                 | 锁定执行时间，冷却期内忽略触发       |
| 比喻     | 电梯等人：最后一个人进来后延迟关门   | 地铁发车：固定时间一班，不管多少人   |
| 典型场景 | 搜索框输入联想，窗口resize，表单校验 | 滚动加载、鼠标移动、按钮防连点、拖拽 |
